ARKYNTECH GRAC - OPTIMIZACION DE MEMORIA PARA RENDER

Archivo listo: Programasgsi2_RENDER_MEMORIA_OPTIMIZADA.py

QUE CAMBIO
- pandas, numpy, matplotlib.pyplot y algunas utilidades graficas dejan de importarse indiscriminadamente al inicio.
- Se importan dentro de las funciones que requieren estas bibliotecas, incluido openpyxl.load_workbook.
- No se eliminaron rutas, modulos ni las bases SQLite.
- Se verifico la sintaxis con python -m py_compile y se comparo el numero de funciones y rutas Flask.

IMPORTANTE
- Aun no se ha probado GRAC integralmente contra sus bases de datos ni se ha medido su RAM real en Render.
- Estas importaciones diferidas reducen potencialmente el consumo inicial, pero cuando se accede a los informes y graficos las bibliotecas permaneceran cargadas en el proceso.
- Si la aplicacion aun supera 512 MB al usar graficos, hay que perfilar las rutas especificas y optimizar la gestion de figuras y consultas.
- requirements.txt original se conserva sin modificaciones para no causar incompatibilidades por borrar dependencias.

COMO IMPLEMENTAR
1. Guarda una copia de seguridad de Programasgsi2.py y de las bases de datos; no las borres.
2. En GitHub, sube el archivo optimizado con el NOMBRE EXACTO Programasgsi2.py reemplazando el anterior (si esa es la ruta de tu repositorio).
3. No alteres el Start Command configurado: gunicorn --workers 1 --threads 2 --worker-class gthread --timeout 120 --max-requests 200 --max-requests-jitter 30 --bind 0.0.0.0:${PORT:-10000} Programasgsi2:app
4. En Render, espera Deploy -> Live. Prueba login, dashboard, riesgos, SOA, graficos PDF, exportacion Excel y sesiones.
5. Revisa Events y Metrics durante al menos algunos accesos reales.
6. Si falla el despliegue, restaura Programasgsi2.py anterior desde el commit precedente en GitHub.

CONSIDERACION EXTRA
La version actual contiene @app.after_request que convierte y reescribe contenido HTML, lo cual puede causar asignaciones temporales grandes. No se modifico aqui porque requiere pruebas especificas de interfaz y cierre de sesion.
